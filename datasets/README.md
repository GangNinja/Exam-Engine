# Datasets

* `sample/` — the committed **synthetic** development dataset (2 courses, 7 files).
  Everything in it is generated by [`tools/build_sample_dataset.py`](../tools/build_sample_dataset.py)
  and is explicitly labelled synthetic. It is **not** official exam material.
* `analytics_sample/` — a **synthetic** three-session course used to demonstrate
  Phase 4 repetition, marks and observed-period trends. Its exam metadata is
  fabricated for testing and must not be presented as university history.
* `templates/manifest.example.json` — copy this to start a new dataset import.

Import the sample:

```bash
python -m exam_engine init-db
python -m exam_engine import datasets/sample/manifest.json
```

Regenerate it:

```bash
python tools/build_sample_dataset.py
```

Import and analyse the synthetic analytics fixture:

```bash
python -m exam_engine import datasets/analytics_sample/manifest.json
python -m exam_engine understanding analyze
python -m exam_engine analytics report --course demo-analytics-cs201-2024-v1
python -m exam_engine graph build --course demo-analytics-cs201-2024-v1
python -m exam_engine graph status
python -m exam_engine exam-dna profile --course demo-analytics-cs201-2024-v1
python -m exam_engine coverage report --course demo-analytics-cs201-2024-v1
```

The graph and coverage report use the same synthetic course; relationships,
coverage findings and exam sessions are fixture data, not verified educational
facts or real examination history.

Read [docs/datasets.md](../docs/datasets.md) before adding external material: it
covers provenance fields, licensing rules, versioning a course, and the Phase 13
boundary for personal data.

Do not commit downloaded papers unless their licence clearly permits
redistribution.
